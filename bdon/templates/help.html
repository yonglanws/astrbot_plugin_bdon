搜索技巧 · 游戏文本默认使用简体中文；加 tw / hk 前缀切换为繁体，例如贴纸名会显示「燈貼圖1」。 · 关键词支持简体、繁体、日文、英文、韩文，或直接输入数字 ID；不同写法都能搜到同一条结果。 · 支持角色别名：灯、tomori、rana、soyo 等社区常用写法均可搜索。 · 多个关键词用空格分隔，会同时匹配标题、角色、乐队等字段。 · 列表不分页；查歌 / 查卡不带关键词时只展示最近 20 条，发送关键词即可搜索全部内容。 · 查活动 不带参数查看当前活动；活动一览 查看全部活动。 · card ID / scard ID 直接返回卡面原图；查贴纸 ID、查漫画 ID 直接返回原图。 · 区服前缀可以连写，也可以加空格：jp查歌 与 jp 查歌 等价。
